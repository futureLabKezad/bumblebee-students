# gates (вариант «r2j + камера полных строк»)

Файлов здесь сейчас НЕТ, поэтому установка и откат варианта заблокированы. Создаёт ТОЛЬКО чат 1 и только после слов владельца. Claude-сборщик эти файлы не создаёт.

## S2_S3_PASSED.txt (как у основного образа, но для ЭТОГО манифеста)
```
S2=PASS
S3=PASS
ДАТА=<дата>
ДОКАЗАТЕЛЬСТВО=<путь к отчёту S2/S3 на r2jf и его sha256>
ОБРАЗ_MANIFEST_SHA256=<sha256 файла image_manifest.final.tsv этой папки>
СОЗДАЛ=чат 1
```
