# gates - разрешения для 07_vzlet_zagotovka.cmd (создаёт только чат 1)

Файла `TAKEOFF_APPROVED.txt` здесь сейчас НЕТ, поэтому взлёт заблокирован. Чат 1 создаёт его только после слов владельца о шаге 14 (взлёт), строками:

```
ШАГ=14
ВЗЛЁТ_РАЗРЕШИЛ=владелец
ДАТА=<дата и время>
СЛОВА_ВЛАДЕЛЬЦА=<дословно>
СКРИПТ_SHA256=<тот же sha256, что в takeoff.conf>
АРГУМЕНТЫ=<ровно то же, что SCRIPT_ARGS в takeoff.conf (номер полёта и т.п.); строка обязательна, значение может быть пустым>
СОЗДАЛ=чат 1
```

Скрипт (по sha256) и его аргументы привязаны к разрешению: изменить SCRIPT_ARGS в takeoff.conf после одобрения нельзя, иначе запуск откажет. Свободных аргументов у `07_vzlet_zagotovka.cmd` нет: он ничего не пробрасывает из командной строки.

## OVERLAY_MAVROS_APPROVED.txt и OVERLAY_BUMBLEBEE_APPROVED.txt (подключение собранного оверлея, 16_podkljuchit_overlay.cmd)
Файлов сейчас НЕТ, поэтому подключение заблокировано. Создаёт ТОЛЬКО чат 1 и только после слов владельца «да» на подключение именно этого оверлея (решение утром). Формат (строки, порядок любой):
```
ПОДКЛЮЧИТЬ=<mavros или bumblebee>
ВЛАДЕЛЕЦ_СКАЗАЛ=да
ДАТА=<дата и время>
СЛОВА_ВЛАДЕЛЬЦА=<дословно>
ОТПЕЧАТКИ_SHA256=<sha256 файла out\fingerprint_<цель>_*.txt, самого свежего, с «# VERDICT OK»; снимается шагом 15 после сборки>
СОЗДАЛ=чат 1
```
Разрешение привязано к файлу отпечатков: после новой сборки или нового снятия отпечатков нужно новое разрешение. Откат (17_otkljuchit_overlay.cmd) разрешения не требует.
