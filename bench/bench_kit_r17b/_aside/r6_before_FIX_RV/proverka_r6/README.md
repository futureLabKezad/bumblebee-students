# proverka_r6 — как проверялся набор r6 (Claude, 12.11.2026)

К дрону ничего из этой папки не обращается. Всё — на подделках ssh/scp и командах Pi, в песочницах.
| Файл | Что |
|---|---|
| `run_all_tests_r6.ps1` | прогон всех тестов по одному (один поток): r5 — стенд, Pi, образ; r6 — ПК и Pi. Процессы тестов — с приоритетом ниже обычного; всё, что идёт в WSL, — через обёртку `wsl.exe` (`wsl_nice_wrapper.cs`, собирается во временной папке Windows): дистрибутив Ubuntu-24.04, `nice -n 19 ionice -c3` (рядом работает Симулятор). Тесты r5 при этом не правятся (кроме двух путей, см. README набора). Итоги — `tests_r6_svodka.txt`, вывод каждого — `tests_*_console.txt` |
| `mutation_check_r6.sh` | «у тестов есть зубы»: на копии портит по одному месту в `pi\r6_*.sh` (8 правок: нет проверки имени хоста, свой процесс считается camera_fix, mask без --now, TF детектора не в /bench, ros2 без --no-daemon, нет отказа перезаписи, нет проверки исполняемого префикса, нет условия «до правки enabled») и проверяет, что `tests\run_tests_r6_pi.sh` это ловит. Итог — `mutation_check_r6.txt` |
| `make_diff_sums_r6.py` | `DIFF_r5_r6.txt` (перенесённые файлы называются «ПЕРЕНЕСЁН») и `SHA256SUMS.txt`; прежний SHA256SUMS (копия r5) не удаляется — `_aside\SHA256SUMS_r5_copy.txt` |
| `scan_echo_r6.txt` | вывод `proverka_r5\scan_echo.py` по r6: опасный текст в echo всех .cmd (новых находок нет: 6 известных из r5 — настоящие команды) и первая строка каждого .cmd |
