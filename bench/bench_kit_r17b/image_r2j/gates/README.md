# gates

Здесь лежит `S2_S3_PASSED.txt`. Его создаёт ТОЛЬКО чат 1 (оркестратор) и только после того, как сам проверил: в SITL пройдены S2 и S3 (правило 14 /work/CLAUDE.md). Другие чаты этот файл не создают и не правят.
Флаг привязан к образу: `check_gates.ps1` сравнивает ОБРАЗ_MANIFEST_SHA256 с реальным sha256 `image_manifest.final.tsv`. Флаг, выданный для другого образа или для манифеста, который потом изменили, установку не разрешает. Файл кладётся в `image_r2j\gates\` (не в корневую `gates\`).
В тестах набора подставляется копия в песочнице.

Формат (строки, порядок любой):
```
S2=PASS
S3=PASS
ДАТА=2026-ММ-ДД
ДОКАЗАТЕЛЬСТВО=<путь к отчёту S2/S3 и его sha256>
ОБРАЗ_MANIFEST_SHA256=<sha256 файла image_manifest.final.tsv именно этого образа r2j (вместе с hover r6, MAVROS bp02 и камерой по умолчанию)>
СОЗДАЛ=чат 1
```
