# Ubuntu 24.04 (noble) packages for the simulator trial, installed with
# --no-install-recommends by install_deps.sh.
#
# Versions: in CI every Ubuntu package (these and all their dependencies)
# comes from one dated archive snapshot (UBUNTU_SNAPSHOT in
# .github/workflows/sim-trial.yml), so the whole set is fixed by that date.
# The Lima VM (arm64) uses its normal archive; the trial records the exact
# installed versions (packages.tsv) on both.
#
# Based on PX4 v1.16.1 Tools/setup/ubuntu.sh (general + simulation sections)
# minus tools the SITL build does not use (astyle, cppcheck, gdb, lcov,
# shellcheck, NuttX toolchain) and minus the GStreamer dev packages: with them
# PX4 builds GstCameraSystem, which H.264-encodes a camera with x264 on the
# CPU. Our drone software never does that, so it would only skew the RTF.
