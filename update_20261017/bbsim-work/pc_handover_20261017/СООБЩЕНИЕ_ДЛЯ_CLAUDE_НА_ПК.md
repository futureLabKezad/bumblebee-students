## Владельцу: сначала шаги в Windows (по порядку)

1. Компьютер включён в розетку. Пуск → Параметры → Система → Питание: «Переводить в спящий режим» = **Никогда**, пока идут установка и испытания. Обновления Windows поставьте на паузу (Параметры → Центр обновления Windows → Приостановить).
2. Обновите драйвер видеокарты NVIDIA в Windows (приложение NVIDIA или nvidia.com). Внутрь Ubuntu никакой драйвер ставить не нужно.
3. Откройте PowerShell от имени администратора (Пуск → наберите «PowerShell» → правая кнопка → «Запуск от имени администратора») и выполните:
   ```
   wsl --install -d Ubuntu-24.04
   ```
   Потом перезагрузите компьютер. Если команда пишет про виртуализацию, включите её в BIOS (SVM у AMD или VT-x у Intel) и повторите.
4. После перезагрузки откроется окно Ubuntu. Придумайте имя (латиницей, маленькими буквами) и пароль. **Пароль запомните.** Вводить его будете только вы.
5. В PowerShell (можно обычном) выполните по очереди:
   ```
   wsl --update
   wsl --shutdown        (это закроет Ubuntu и Claude в ней; потом откройте Ubuntu снова)
   wsl --version
   ```
   Скопируйте вывод последней команды: его нужно вставить в конец сообщения ниже.
6. Снова откройте Ubuntu: Пуск → «Ubuntu 24.04». Или в Windows Terminal стрелка ˅ → «Ubuntu 24.04».
7. В окне Ubuntu поставьте Claude Code:
   ```
   curl -fsSL https://claude.ai/install.sh | bash
   ```
   Затем наберите `claude` и войдите в тот же аккаунт, что и на Mac. Если пишет «command not found», закройте окно Ubuntu, откройте снова (шаг 6) и наберите `claude` ещё раз.
8. Скопируйте в Claude всё, что ниже между линиями. Вставка в окне Ubuntu: правая кнопка мыши или Ctrl+Shift+V.

**Важно, пока идут установка и испытания:**
- Команды с `sudo` запускайте во **втором** окне Ubuntu: в Windows Terminal кнопка «+» (или ˅ → Ubuntu 24.04), либо Пуск → «Ubuntu 24.04» ещё раз. Вставьте команду туда и там же введите пароль. **Пароль никогда не вводите в окно Claude.**
- Окно, где работает Claude, не закрывайте: это останавливает его работу.
- Компьютер в розетке и не засыпает.
