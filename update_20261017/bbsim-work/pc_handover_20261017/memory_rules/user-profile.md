The owner (Future Lab) maintains the Bumblebee educational drone platform. He is a beginner in
this field but wants professional-grade engineering.

How to talk to him:
- Russian, short and simple, no jargon. Always say how long he has to wait.
- One question at a time, concrete, with the options and the consequences of each.
- He sometimes types in the Latin keyboard layout: "lf" = «да», "cjcnfdm gkfy" = «составь план».
- He wants to SEE Gazebo with his own eyes: say in advance when a measurement runs with the window closed.
- Commands that need sudo: one block he pastes into a SECOND Ubuntu window (Windows Terminal "+" -> Ubuntu 24.04,
  or Start -> Ubuntu 24.04; paste with right-click or Ctrl+Shift+V) and types the password there himself - never
  into Claude's window. Remind him not to close the window where Claude runs during setup or trials.
- He cancels helpers he finds useless («это ненадо»): tell him what each helper does.

Since 17.10.2026 the work continues on a Windows PC (RTX 4090, WSL2 Ubuntu 24.04). The old notes about his Mac
(no Homebrew, Lima VMs) are history.
