# Обновление снимка от 17.10.2026

Это дополнение к полному снимку от 15.10 (архив `workspace.tar.gz.part*` в корне ветки). Здесь лежат все файлы рабочей папки `bbsim-work`, которые появились или изменились после снимка: 418 файлов, около 100 МБ, с контрольными суммами в `MANIFEST_SHA256.json`.

Что внутри:

- `bbsim-work/parallel_work/20261015/integration/flight_trial_02/` — исправленная копия исполнителя испытаний: порог скорости симуляции 0,20, обнаружение сна компьютера, понятные сообщения проверок. Исходный `flight_trial_01` не менялся.
- `bbsim-work/parallel_work/20261015/integration/flight_trial_03/` — то же, но с полем по измерениям владельца (`field_measurements_01`).
- `bbsim-work/sim/runs/` — все запуски 17.10, включая неуспешные и недействительные.
- `bbsim-work/pc_handover_20261017/` — передача работы на ПК с Windows и RTX 4090:
  - `ПЕРЕДАЧА_НА_ПК.md` — полный документ;
  - `СООБЩЕНИЕ_ДЛЯ_CLAUDE_НА_ПК.md` — короткое сообщение для вставки в Claude Code на ПК;
  - `setup/` — скрипты установки WSL Ubuntu 24.04 и восстановления этого снимка;
  - `vm_inventory/` — точные версии из прежней ВМ;
  - `memory_rules/` — правила работы.
- `workspace_root_docs/` — один общий документ («Симулятор — Isaac Sim или Gazebo»). Остальные документы из корня рабочей папки не опубликованы: в них есть сведения о безопасности настоящих дронов.

Порядок восстановления описан в `bbsim-work/pc_handover_20261017/setup/restore_snapshot.sh` и в документе передачи. Сначала восстанавливается архив 15.10, затем поверх кладётся эта папка с проверкой каждой контрольной суммы.

Полётный пакет не принят. Настоящий дрон не использовался.
