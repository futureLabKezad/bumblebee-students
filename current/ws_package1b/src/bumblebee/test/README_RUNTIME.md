# Исполнитель изолированных тестов ROS

Шесть тестов используют `executor_support.CooperativeExecutor`. После каждого вызова исходного `_spin_once_impl` выполняется `time.sleep(0)`, чтобы другие потоки Python получили время выполнения. Обработчики, группы, четыре рабочих потока и исходные условия проверок сохранены. Клиент RPC использует прежний `SingleThreadedExecutor`. Установленный rclpy, C++ контроллер и SDK не изменены.

В сравнении на rclpy 7.1.12 исходный вариант `current_b327_b` имел максимальную задержку команды при ожидающей телеметрии 1,908 с. В `current_b327_yield` она составила 0,003869 с; все девять исходных условий RPC прошли. Данные сохранены в `analysis/diagnosticsRPC/` от корня рабочей папки. Предыдущие ошибки полного набора находятся в `analysis/plans_2026-10-14/package1b_current_b327_full_tests.log`.

В [исходнике rclpy rolling](https://github.com/ros2/rclpy/blob/rolling/rclpy/rclpy/executors.py#L1039-L1040) после отправки обработчика и проверки завершённых задач также освобождается GIL: `os.sched_yield()` с запасным `time.sleep(0)`. [Issue 1223](https://github.com/ros2/rclpy/issues/1223) содержит сообщения о задержках таймеров. Наш вариант вызывает исходный диспетчер целиком и не копирует его код. Исходное исключение сохраняется даже при вторичной ошибке освобождения потока.

Таймер позы FakeMavros имеет период 1/30 секунды часов узла. В faithful-режиме heartbeat имеет период 1 секунду, в прежнем быстром режиме 0,2 секунды. В тесте `use_sim_time` эти интервалы относятся к `/clock` при RTF 0,25. Группа команд остаётся `MutuallyExclusiveCallbackGroup`, задержка ACK выполняется прежним способом. Таймер целей C++ использует физическое время. Пороги RPC 0,3 с, пауз heartbeat, отсутствие целей после отмены и 600 наборов батарейных данных не изменены.

Проверка наследованного вызова и исключений без ROS:

```sh
python3 ws_package1b/src/bumblebee/test/test_executor_support.py
```

Сравнение RPC и проверки тестового исполнителя не подтверждают физический сценарий S3. Для него нужен отдельный полёт SITL с проверкой истинной высоты, режимов PX4 и пакетов целей.
