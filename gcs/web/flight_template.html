            Drone: map and mission
            
      
            Through the mission server on the drone (bb_mission). The app itself never arms and sends no setpoints: it asks the server, which runs the program under the guards. Simulate first: the Program tab must show no errors.
            
      
            
        
        
        no connection
      
            
      
            
        
        
      
            
      
            
      
            Battery 6S LiHV 4500 mAh (full 4.35 V/cell = 26.1 V). The owner’s threshold is 20 V by multimeter: land at once. PX4 over-reads the voltage, the more so the lower the charge, so the drone lands at 23.0 V by PX4. The PX4 charge percentage is wrong: it assumes 4.2 V/cell. There is no current sensor, so the flight time is counted only by the timer (budget).
