## Коротко
1. **Главное, новое (доказано по журналам).** С 11.08 01:08 (журнал 121) до последнего полёта 13.08 (журнал 148) автопилот ни разу не использовал датчик потока в воздухе: 0 % в 12 журналах, где дрон был в воздухе 5 с и больше. До этого, в журналах 0–114, поток работал почти в каждом полёте: медиана 79 % времени в воздухе по 72 журналам; исключение — журнал 108 (1 %).
   - Без потока у дрона нет положения по горизонтали: GPS нет, зрение выключено.
   - Взлёт в режиме Position 6 раз кончился так: через 5–8 с после взвода «слепая посадка» (Failsafe: blind land), и пилот выключал моторы аварийным выключателем (журналы 128, 129, 132, 135, 136, 145).
   - Дальше 13.08 летали вручную, в режиме STAB (журналы 146–148).
2. **Почему — скорее всего.** Настройки 13.08 — они же сейчас на 20EC:
   - высота по дальномеру (EKF2_HGT_REF = 2), дальномер всегда (EKF2_RNG_CTRL = 2), зрение выключено (EKF2_EV_CTRL = 0);
   - по коду PX4 1.16.1 (тот же коммит, что на дроне) при таких настройках автопилот не оценивает рельеф. А поток запускается только при оценённом рельефе или при другом источнике положения;
   - строки кода — в `august_extra.txt`, раздел 5.
   - «Доказано» будет после контроля в Gazebo (шаг 4): с теми же настройками поток не запускается, с одной правкой — запускается.
3. **Что это значит для цели — скорее всего.**
   - На нынешних настройках 20EC дрон не удержит место и не полетит скриптом ни по меткам, ни по миссии.
   - Вариант А («как сейчас, без зрения») без правки настроек не полетит.
   - Честный Gazebo (правило 12: симулятор повторяет дрон) должен показать то же самое.
   - Правка настроек дрона — ваше решение (правило 5, вопросы 7–8), и только после проверки в Gazebo.
4. **Числа для С3.** Поток — 63 Гц (доказано). Дальномер — около 50 Гц (скорее всего). На земле дальномер показывает 0,18–0,20 м (доказано).
5. **Числа для С4.** Эталон 147–148 (13.08):
