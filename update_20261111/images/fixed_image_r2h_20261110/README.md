## Чего тесты не покажут
- **Состав С8 (для A10), доказано на стенде без ROS.** В С8 vpe_fix обёрнут модулем freshness (`vpe_freshness_optin`). Он пропускает только самую новую позу, поэтому медоиду Б2 отбрасывает: после паузы бывают новые дыры до 0,70 с.
  - На дроне обёртки нет: `aruco.launch.py` запускает vpe_fix.py напрямую.
  - Образ это не меняет. Выбор за чатом 1, подробности: `notes/T44_freshness_vs_B2.md`.
- Реальная частота детектора на Pi не измерена (как у кандидата).
- Сторож W меряет время симуляции, только если drone.py запущен с use_sim_time (как у кандидата, N5).
