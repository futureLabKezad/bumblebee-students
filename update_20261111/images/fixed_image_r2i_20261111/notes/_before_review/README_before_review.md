**Почему от взвода, а не от вызова `takeoff()`** (по коду):
- сторож работает только при «вооружён» (`navigate_wait`: `t.armed`); до взвода моторы стоят, риска нет;

- `takeoff()` вызывается не перед каждым `navigate_wait` (например `fly_to` после взвода с пульта — тогда отсчёта не было бы);
- предел взлёта 25 с задан как «взвод + медленный подъём» (комментарий `takeoff`, T30: зрение пропадает у пола при раскрутке) — отсчёт от взвода его смысл сохраняет. ## Как скрипт узнаёт «зрение есть» (для «Скриптов полёта», hover r5)
- **Функция:** `drone.vision_pose_age()` — секунды с последней НОВОЙ позы vpe_fix; `float('inf')`, если поз ещё не было.
  - «зрение есть» = `drone.vision_pose_age() <= 1.0`; «молчит» = `> 1.0` (как сделано в `flight.py` и `flight_marker*.py`).
  - Работает после любого вызова, который делает `_init()` (любая лётная команда, `require_vpe_link`, `takeoff`). Подписка — в `_init()`, отдельного потока не нужно.
  - Источник: топик `/mavros/mavros/pose_cov` (`PoseWithCovarianceStamped`), подписка BEST_EFFORT, глубина 10. Повтор той же позы не обновляет время.
- **Не использовать** для зрения в полёте: `drone._aruco_markers_used`, `drone._markers_used_age()`, `drone._markers_pos_age()` — это сырой счёт детектора, ложные кадры в нём есть.
- **Пример (висение со сторожем):**
  ```python
  silent_since = None
  while time.time() < end and not drone.should_land:
      if drone.vision_pose_age() > 1.0:
          if silent_since is None:
              silent_since = time.time()
          elif time.time() - silent_since > 3.0:
              break                      # -> finally: drone.safe_land()
      else:
          silent_since = None
      time.sleep(0.1)
  ```
