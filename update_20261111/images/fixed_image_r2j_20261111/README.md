## Известные отличия и уточнения из проверки r2i (решение чата 1, 11.11: вариант (а), код vpe_fix не менять)
- **Известное отличие.** При потере только HEARTBEAT simple_offboard (r2i/r2j) ведёт поток до 5,5 с после последнего HEARTBEAT, а vpe_fix закрывает зрение через 4,5 с без State (`_STATE_STALE_TIMEOUT`, правило P1, утверждено владельцем 21.10).
  - В OFFBOARD возможны 0,5–1 с без зрения, потом возврат через медоиду Б2.
  - Код vpe_fix, его байты и пины не меняются.
  - Комментарий `vpe_fix.py:179–181` («зрение не режется, пока simple_offboard ведёт поток») для этого случая неточен.
- **Уточнения к README r2i.**
  - Остановка при потере только HEARTBEAT приходит **до возврата HEARTBEAT**, а не «до конца разрыва»: heartbeat_13 — разрыв кончился 74,464, остановка 74,967, HEARTBEAT вернулся 75,436.
  - После полной потери связи остановка может прийти **до 33 мс раньше 4,5 с** (шаг отсчётов потока 30 Гц).
- **`state_heartbeat_period`** (1,0 с) не проверяется на диапазон. Значение на дроне не меняется, проверку не добавляли (решение чата 1).
